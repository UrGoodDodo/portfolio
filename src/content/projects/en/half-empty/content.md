## overview

![Half Empty](/images/projects/half-empty/cover.webp "wide")

Half Empty is a game created for a MMCS GameJam.

My main responsibility in the project was the visual side of the scene: building the background, selecting suitable 3D models, and creating shaders and materials that helped shape the final visual style of the game.

## technical-breakdown

### Contribution

My main contribution to the project was the visual design of the environment.

I searched for suitable 3D assets, arranged them to build the background, and worked on the overall composition of the scene. I also created and adjusted shaders and materials to help bring the different assets together visually.

Since Half Empty was developed during a GameJam, most of this work had to be done within a limited amount of time. The goal was to quickly create a cohesive environment using available assets while adding custom visual elements where needed.
